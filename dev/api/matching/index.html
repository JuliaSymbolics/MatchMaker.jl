Matching

Compile a pattern once, then match it against subjects. All match functions accept a Matcher or a raw expression (compiled via compile_pattern); constraints takes cross-variable Constraints and maxsteps bounds engine work.

Compilation

Compile expr into a Matcher. vars maps pattern variables (inner Syms or marker terms) to VarSpec variants (slotspec/segmentspec); unlisted variables get the unconstrained spec for their kind.

MatchMaker.boundmatches — Function
boundmatches(
    m::Matcher,
    s::SymbolicUtils.BasicSymbolicImpl.var"typeof(BasicSymbolicImpl)"{SymReal};
    constraints,
    maxsteps
) -> BoundMatchIterator

Lazy iterator of all matches of m against s like matches, but each item is a BoundMatch: a persistent snapshot of the index-only binding state that reconstructs segment terms on access. Far cheaper per result than materializing a MarkersMap — use it when collecting many results, or when the consumer reads only a few bound values per match.

source
MatchMaker.boundmatchall — Function
boundmatchall(m, s; kwargs...) -> Vector{Any}

collect(boundmatches(m, s)) — all matches as a Vector{BoundMatch}. The cheap matchall for enumeration-heavy workloads (~10× faster on segment-heavy cases); materialize individual results to get the same MarkersMaps matchall returns.

MatchMaker.BoundMatchAtIterator — Type
BoundMatchAtIterator

Lazy iterator over match sites — yields (BoundMatch, t) pairs: a frozen binding snapshot and the matched subterm, one per (pattern-match, node) in postorder. materialize(bm) a pair's first element for a MarkersMap.

The subject is interned once into the engine's shared IR, so a structurally shared subterm is one node and yields one hit — sites are deduplicated by ===-identity, not by syntactic position (REWRITING.md milestone 4).

Cross-variable constraints

MatchMaker.Constraint — Type
Constraint(fn, vars)

A cross-variable constraint (DESIGN.md §4.9): fn is called with a Vector{BasicSymbolic{SymReal}} of bound values in vars order and must return Bool. Fires as soon as every variable in vars is bound. vars elements are variable Syms or marker terms.

Instantiation

MatchMaker.instantiate — Function
instantiate(
    template::SymbolicUtils.BasicSymbolicImpl.var"typeof(BasicSymbolicImpl)"{SymReal},
    subst
) -> SymbolicUtils.BasicSymbolicImpl.var"typeof(BasicSymbolicImpl)"{SymReal}

Rebuild template, replacing marker terms with their bound values from subst (a MarkersMap or any dict keyed on variable syms/marker terms). slot/optional vars substitute their bound expression; segment vars splice arguments(bound) into the parent's argument list (a Const segment binding contributes zero arguments); a head marker (slot(f)(…)) substitutes the raw bound operation.

Extended help

Iterates the template's IRStructure in postorder building out[i] — no recursion. For templates without segment or head markers, SymbolicUtils.IRSubstituter gives the same result; instantiate is required for splicing and head substitution.
