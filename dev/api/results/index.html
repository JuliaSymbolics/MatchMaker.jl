Results

Match results are bindings from variable Sym to bound expression, exposed at three price points:

  • SubstitutionView — zero-cost live view, valid only inside eachmatch's callback or until the next iterate step.
  • BoundMatch — frozen snapshot, lazy per-variable resolution; the cheap thing to collect.
  • MarkersMap — fully materialized dictionary; the simple, self-contained result.
MatchMaker.MarkersMap — Type
MarkersMap <: AbstractDict{BasicSymbolic{SymReal}, BasicSymbolic{SymReal}}

A materialized match: variable Sym → bound expression. Segment variables bind to the reconstructed f(captured…) under their parent head (§5.6), so the value type is uniformly BasicSymbolic{SymReal}.

Key lookup is normalized through unwrap_varspec: d[x], d[slot(x)], d[segment(x)], d[optional(x)] all resolve to the same variable. Keys are stored as inner Syms only — keys/iterate therefore yield plain symbolic variables.

MatchMaker.SubstitutionView — Type
SubstitutionView <: AbstractDict{BasicSymbolic{SymReal}, BasicSymbolic{SymReal}}

A read-only view of a match's live engine bindings, resolved lazily. Valid only until the next eachmatch/iterate step mutates the bindings — copy with materialize to keep results. With the strict_views preference enabled, stale access throws.

source
MatchMaker.BoundMatch — Type
BoundMatch <: AbstractDict{BasicSymbolic{SymReal}, BasicSymbolic{SymReal}}

A persistent match result — a frozen copy of the bindings, resolved lazily on access. Returned by boundmatches, boundmatchall, and boundmatches_at; cheap to collect when the consumer inspects only a few bound values per match. Copy into a MarkersMap with materialize.

MatchMaker.BoundMatchIterator — Type
BoundMatchIterator

Lazy iterator over successive matches — one BoundMatch snapshot per state. Much cheaper per result than MatchIterator (frozen binding state, no term reconstruction); materialize individual results with materialize.
